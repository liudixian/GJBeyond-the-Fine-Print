# 《细则之外：租客规约》2D 原型

打开 `index.html` 即可试玩。建议用 Chrome/Edge 直接双击打开，或在当前目录启动一个静态服务器。

## 推荐试玩路径

1. 点击门上的守则，阅读完整规则。
2. 点击窗，触发三下敲窗声；先不要拉窗帘。
3. 点击冰箱、植物、镜子、拖鞋、时钟，观察规则之间的矛盾和互相提示。
4. 点击“回应敲门”，体验“不要回应”与“回应相同节奏”的缝隙。
5. 点击“推进时间”两次，看到 3:33 水龙头事件。
6. 收集足够线索且异常为 0 后，点击“尝试退租”测试安全结局。
7. 也可以重复浇植物、触发镜中动作，测试异常和坏结局。

## 这一版验证的设计问题

- 玩家是否愿意先读一整张规则，再开始点击探索。
- “规则本身就是谜题线索”的信息反馈是否清楚。
- 矛盾规则是否会促使玩家记录、比较和试错。
- 异常值、线索数和日志是否足够支撑解谜过程。
- 退租按钮是否能成为一个明确的阶段目标。

## 当前范围

这是一个纯 HTML/CSS/JavaScript 的 2D 可玩原型，使用点击热点、文字日志、规则面板和结局弹窗模拟安全屋循环。它暂时不依赖 Unreal 资源，适合先验证解谜流程、文案和节奏，再决定是否移植到正式项目。
