# 《细则之外：租客规约》规则涌现原型

打开 `index.html` 即可试玩。建议用 Chrome/Edge 直接打开，或在本目录启动静态服务器。

## 这版新增的玩法

- **时间与事件窗口**：推进时间会触发清晨房东检查、凌晨 3:33 水龙头和 23:50 午夜实验窗口。
- **警觉度与痕迹**：开窗、拉开窗帘、模仿镜像、反复回应等行为会留下痕迹，影响房东检查与退租。
- **多状态物件**：牛奶有口数，植物会正常、朝向窗户或开始模仿，镜子会变脏、洁净并记录异常。
- **假设记录板**：先做实验，再点击“验证”，把“植物导航”“敲门节奏”“镜子记录”“午夜反向规则”等猜想变成已验证知识。
- **午夜实验**：选择喝光牛奶、把规则反向执行、打开窗户或使用手电筒，尝试改变房间对你的定位。
- **多结局**：安全离开、规则之外、永远租客，取决于异常、警觉、验证的假设和实验结果。

## 推荐试玩路径

1. 点击入户门，阅读守则和退租附则。
2. 调查冰箱、植物、镜子、拖鞋、窗和时钟。
3. 点击“等待 10 分钟”观察时间推进；点击“回应敲门”记录节奏。
4. 先倒一口牛奶给植物，再查看它是否朝向窗户；第二次操作会让它开始模仿。
5. 点击“午夜实验”，尝试“喝光牛奶，拖鞋朝内，窗帘合上”。
6. 回到假设记录板，验证已经满足条件的猜想。
7. 点击“放回守则”，再尝试退租。不同实验和痕迹会进入不同结局。

## 设计目标

这一版用少量状态变量测试“规则即实验条件”的玩法：每个动作都会改变时间、异常、警觉或物件状态；失败会提供额外信息；玩家需要提出假设、验证因果，并决定自己追求安全退租、破解规则还是主动靠近异常。
