# 细则之外：租客规约 · 平面探索原型 0.3

直接用 Chrome / Edge 打开 `index.html`，无需构建、服务端或联网。音效由 Web Audio 实时合成，首次按键或点击后启用。

## 操作

- `W A S D` 或方向键：移动。墙和家具有碰撞。
- 靠近物件后按 `E`：调查，再点击对话选项执行动作。不能隔墙互动。
- `J`：心理笔记；`Esc`：关闭对话。
- 顶部可静音、查看成就簿、开始新周目；窄屏提供触摸方向键。
- 移动和阅读不推进时间；执行动作默认 2 分钟。等待、休息、楼层切换按各自耗时结算。
- 本机自动保存位置、剧情、资源与当前结局。新周目保留成就 / 结局收藏；浏览器不允许本地存储时会显示提示。`file://` 和 HTTP 下的收藏相互独立。

## 地图与路线

- **安全屋**：客厅、厨房、主卧、玄关、仓库、卫生间、卧室 3 和连接走廊。
- **阁楼**：原初法则涂鸦、午夜钟表、仪式台、检修梯。
- **地下室**：巡检档案、熄灯走廊、无名协议、货梯。23:00–3:33 可进入，必须在 3:33 前完成返程，楼梯也需要 2 分钟。移动、阅读不消耗倒计时，执行动作才消耗。
- **镜后空间**：擦净镜面并阅读阁楼法则后可进入，管理员终端提供三项考核。

建议第一次先走：读门上须知 → 鞋柜拿清洁用品 → 仓库拿钥匙、照片、手电 → 卧室 3 读日记 → 阁楼读涂鸦 → 回书桌推导规则起源 → 选择仪式、反向规则或终端。

## 规则与反馈

牛奶只有两口：第一口浇植物没有变化，第二口使叶片转向窗户、留下 30 分钟痕迹。守则、资源和状态共同限制选择。手电只有三次电量；透过合上的窗帘照光可利用规则漏洞。晨检读取窗、鞋与植物的现存痕迹；休息可以降低异常与警觉，但不会清除违规历史。

每次 E 调查、选项操作、关闭页面、解锁成就均有声音与视觉反馈；移动带脚步和步态；开门、流水、布料、钟、异常、仪式、结局使用不同合成音色。页面有物件波纹、粒子、异常抖动、楼层转场和状态外观变化。系统的减少动态效果设置会抑制界面动画。

## 结局与成就（含剧透）

| 结局 | 核心条件 |

| 规则破解者 | 推导起源并读原初法则；午夜亲自喝光两口奶、鞋尖朝内、开窗，在时钟处同步 |
| 房东的真相 | 日记、照片、起源推导，在阁楼午夜仪式呼唤房东名字，再选择解除契约 |
| 自愿留下 | 100 天合规，整个周目从未违规或尝试退租 |
| 周目二：新管理员 | 进入镜后终端、完成起源推导、通过三项考核 |
| 迷失 | 在地下室耗过 3:33 的返程时限 |
| 陷阱 | 相信地下室接替承诺并签字 |
| 永远租客 | 异常达到 8 |

保留笔记中的 7 / 30 / 100 天门槛。床边的连续生活模拟仅在完成真实准备（守则、清洁、窗帘、鞋、空瓶、晚餐）后可用；逐日计时、回应敲门并结算合规天数，避免手动重复生活。

实现 16 项具备条件判定的成就：合格租客、模范租户、沉默是金、房东的日记、捷径之王、规则之外、镜中世界、那是冰箱吗、好奇害死猫、规则漏洞、午夜狂欢、鬼房东、不要睁眼、退租、无限租约、新管理员。五条捷径分别是卧室墙梯、地毯暗道、阁楼检修梯、地下货梯、镜面入口。

结算显示结局叙事、本周目成就、日数、合规天数、区域、互动、违规与捷径统计。成就收藏跨周目保留。管理员结局目前结束于考核和交接，未扩展为可自由编写规则的第二周目。

## 开发与验证

- `engine.js`：确定性规则、资源、时间、成就与结局，无 DOM 依赖。
- `maps.js`：地图、碰撞、可达性与视线判定。
- `game.js`：Canvas 绘制、输入、音效、反馈、对话、存档与结算。
- `style.css`：界面布局与动画。
- `npm ci` 后 `npm test` 运行规则、结局和地图测试。
- `npm run test:browser`：使用本机 Chrome 验证真实按键、UI、声音节点、动画、存档和响应式布局。
- `node tests/journey.cjs`：通过真实键盘穿行四层地图，完成线索链与管理员结局，核对结算和跨周目收藏。需本机 Chrome；截图输出到忽略的 `test-results/`。
